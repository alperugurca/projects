# 🌍 Simple Translator

https://huggingface.co/spaces/alperugurcan/translate

A minimal translation app built with Gradio using the MyMemory API.

## Features

- Translate text between 12+ languages
- Clean and simple interface
- No API keys required
- Ready for Hugging Face Spaces deployment

## Supported Languages

- English, Spanish, French, German, Italian, Portuguese
- Russian, Japanese, Korean, Chinese, Arabic, Hindi

## Usage

1. Enter text in the input box
2. Select source language
3. Select target language
4. Get instant translation

## Deployment

This app is ready to deploy to Hugging Face Spaces. Just upload the files and it will work immediately!

## API

Uses the free MyMemory Translation API: https://mymemory.translated.net/
