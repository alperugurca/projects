# 🛠️ Playground Repo

This repo is my personal sandbox. A place to try things out, test ideas, and keep experiments organized.

## 📂 Structure

-   **`notebooks/`** → Jupyter notebooks (`.ipynb`) for quick
    experiments, notes, and data exploration.  
    
-   **`projects/`** → Multi-file projects. Small apps, prototypes, or bigger experiments.
  
-   **`python/`** → Single Python scripts (`.py`) for utilities, tests,
    or one-off ideas.
    
------------------------------------------------------------------------

✨ Nothing here is too serious. It's just a playground for coding experiments.
