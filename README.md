# 🛠️ Playground Repo

This repo is my personal sandbox --- a place to try things out, test
ideas, and keep experiments organized.

## 📂 Structure

-   **`notebooks/`** → Jupyter notebooks (`.ipynb`) for quick
    experiments, notes, and data exploration.\
-   **`projects/`** → Multi-file Python projects --- small apps,
    prototypes, or bigger experiments.\
-   **`python/`** → Single Python scripts (`.py`) for utilities, tests,
    or one-off ideas.

## 🚀 How to Use

Clone it and poke around:

``` bash
git clone <your-repo-url>
cd <repo-name>
```

Notebooks can be opened in Jupyter or VS Code, and `.py` files run
directly with Python.
