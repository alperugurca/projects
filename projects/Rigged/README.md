# Rigged: The Science of Losing

A satirical Android anti-casino prototype that exposes the underlying mathematics and psychology of gambling through interactive gameplay.

## Overview
`Rigged` masquerades as a standard Vegas-style game (slots and roulette) but progressively degrades visually into raw math and equations as the player's "Enlightenment" increases. It practically demonstrates concepts such as the House Edge, the Gambler's Fallacy, variable ratio reinforcement, and near-miss psychology.

## Core Features
- **Games**: Simplified Slots and American Roulette (0/00).
- **Virtual Croupier**: A reactive companion that responds to outcomes and player behaviors.
- **Educational Progression**: Visual transformation from neon casino aesthetics to mathematical reality.

## Quick Start
Build the debug APK via Gradle:
```powershell
.\gradlew.bat :app:assembleDebug
```
*Output:* `app/build/outputs/apk/debug/`
